HOME PAGE SLIDER - AI IMAGE PROMPTS (Brand Image Media Pvt Ltd)
=================================================================

How to use
----------
1. Paste each prompt into your AI image tool (Gemini, ChatGPT, etc.), one image per prompt.
2. Choose the widest size it offers: 21:9 is best. If it only makes 16:9 or 3:2, that is fine;
   the slider trims a little from the top and bottom.
3. Save each image in this folder ("Slider images") with exactly these names:
      printing.png   shop-branding.png   outdoor.png   transit.png
      wall-painting.png   events.png   promotional.png
   (.jpg or .webp are fine too; keep the same names.)
4. Tell Claude the images are ready. The website adds the text itself (service name, title,
   description, buttons) in the same place on every slide, so the images must NOT contain text.

Tips
- If an image comes out with words or logos on it, ask the tool: "remove all text and logos".
- If the left side is too busy, ask: "make the left 45% a calm, empty deep-blue background".
- Generate all 7 in the same chat so the colours and lighting stay consistent.
